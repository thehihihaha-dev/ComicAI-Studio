# ComicAI Studio

## Giới thiệu

ComicAI Studio là nền tảng AI hỗ trợ:

- 📖 Phân tích truyện tranh
- 🌍 Dịch truyện
- 📝 Tóm tắt nội dung
- 🎙️ Tạo giọng đọc AI
- 🎬 Tạo video YouTube Shorts
- 🎥 Tạo video dài
- 🤖 Quản lý quy trình sản xuất nội dung

## Công nghệ dự kiến

### Frontend

- Next.js
- TypeScript
- Tailwind CSS

### Backend

- FastAPI
- Python

### AI

- OCR
- Translation
- LLM
- TTS

### Database

- PostgreSQL

### DevOps

- Docker

## Mục tiêu

Xây dựng một nền tảng AI giúp tự động hóa quy trình tạo video từ truyện tranh, từ khâu xử lý nội dung đến xuất bản video.
